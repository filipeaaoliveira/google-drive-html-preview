# Drive HTML Preview

Google Drive shows HTML files as source code. This Chromium extension renders
them as web pages instead. It works in Chrome and Brave.

- [Privacy policy](PRIVACY.html)
- [Source code and documentation](https://github.com/filipeaaoliveira/google-drive-html-preview)
- [Download the latest release](https://github.com/filipeaaoliveira/google-drive-html-preview/releases/latest)
